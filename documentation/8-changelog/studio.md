# v1.3.0（2026-10-23）

- 新增小组件（Widget）调试能力，可在模拟调试中直接预览和调试 AIX 声明的小组件，并自动产出小组件预览图用于提审。
- 优化 AIUI Coding 服务的 Skill 加载机制，按需加载并复用 Skill 内容，减少重复注入，提升编码效率与生成稳定性。
- 新增 AIUI Studio 更新日志，按版本沉淀功能新增、体验优化与问题修复。
- 模拟调试升级 Ink 运行时至 0.19。

# v1.2.1（2026-10-15）

- 新增全彩设备调试功能。

# v1.2.0（2026-10-13）

- 优化 AIUI Studio 操作页面布局，拆分模拟调试与真机调试入口。
- 优化 AIUI Coding 服务，提升编码效率及 AIUI 智能体设计能力。
- 优化真机调试面板的操作体验和信息展示，并新增 GPS 模拟功能。
- 真机调试页面新增“意图描述”字段，用于告知 AI 助手调用智能体的适用场景。
- 优化日志及网络信息区域的操作逻辑，支持日志筛选、过滤和隐藏，并允许手动调整窗口大小。
- 优化打包策略，支持打包后向眼镜端推送。
- 优化列表页中的智能体版本信息和审核信息展示，并支持拖拽排序。
- 新增智能体审核通过后的邮件及短信通知。
- 提审页面支持上传最大 50 MB 的智能体视频素材。
- 优化智能体账号关联方案。
- 修复 `.aixignore` 文件不生效的问题。
- 修复提审时缺少“更新日志”的问题。
- 优化实名认证机制。
