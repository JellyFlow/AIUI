# v1.2.0 (2026-10-13)

- Improved the AIUI Studio interface layout with separate entry points for simulator and on-device debugging.
- Improved AIUI Coding to increase coding efficiency and enhance AIUI agent design capabilities.
- Improved the on-device debugging panel's usability and information display, and added GPS simulation.
- Added an "Intent Description" field to the on-device debugging page to tell the AI assistant when to invoke an agent.
- Improved interactions in the log and network information areas, with support for selecting, filtering, and hiding logs, and manually resizing windows.
- Improved packaging to support pushing packages to glasses after packaging.
- Improved agent version and review information in the list view, and added drag-and-drop sorting.
- Added email and SMS notifications when an agent passes review.
- Added support for uploading agent videos up to 50 MB on the review submission page.
- Improved agent account linking.
- Fixed an issue where `.aixignore` files did not take effect.
- Fixed missing changelogs during review submission.
- Improved real-name verification.
