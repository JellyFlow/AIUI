# 开发者工具

AIUI 的开发者工具涵盖 AIUI Studio、AIUI Editor、命令行工具和 Skills，支持从创建工程到预览、设备联调与发布的开发流程。

## 工具目录

- **介绍**：帮助你理解 AIUI 开发者工具的整体定位与使用场景。
- **AIUI Studio 平台**：面向 AIUI 智能体一站式开发构建平台，提供从 AIUI 创建到上架 Rokid 智能体商店的完整链路
- **AIUI Editor**：用于导入项目、编辑文件和预览页面的 Web 开发环境。
- **命令行工具**：使用 `aix` 打包、查看、安装和预览 AIX 项目。
- **Skills**：提供面向 AIUI 开发的专用上下文与规范，帮助你在智能体开发场景中获得更准确的生成与协作结果。
