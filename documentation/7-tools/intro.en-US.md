# Developer Tools

AIUI developer tools include AIUI Studio, AIUI Editor, the command line tool, and Skills. They support creating projects, previewing them, testing on devices, and publishing.

## Tool Directory

- **Introduction**: Helps you understand the overall positioning and usage scenarios of AIUI developer tools.
- **AIUI Studio Platform**: A one-stop development and publishing platform for AIUI agents, providing the complete workflow from creating an AIUI agent to publishing it to the Rokid Agent Store.
- **AIUI Editor**: A web development environment for importing projects, editing files, and previewing pages.
- **Command Line Tool**: Use `aix` to package, inspect, install, and preview AIX projects.
- **Skills**: Provide AIUI-focused context and conventions so agents can generate code and collaborate more accurately in development workflows.

Please select a specific section from the left-side menu to view detailed instructions.
