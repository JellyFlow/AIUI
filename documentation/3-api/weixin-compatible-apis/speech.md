# 语音 (speech)

## 方法

### `wx.speech.playTTS(text)`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `text` | `string` | 是 | 要合成并播放的文本。 |

**返回值：** `string`，底层语音请求标识；无法创建请求时为空字符串。合成以入队方式播放。

### `wx.speech.startRecognition()`

无参数。

**返回值：** `string`，识别会话 ID。识别固定为单次、非连续、无中间结果，最多返回一个候选结果。必须在有效用户交互中调用，否则会抛出状态异常。
