# 数据预拉取

数据预拉取用于在页面真正展示前提前准备请求结果、缓存或关键资源，以缩短首屏等待时间。AIUI 当前尚未公开这一能力的正式接口，本页用于保留文档结构并说明推荐做法。

## 当前状态

- `toc.json` 中该能力标记为 `unsupported`
- 目前没有对外稳定发布的页面级预拉取 API

## 当前推荐做法

- 在页面 `onLoad` 或 `onShow` 中尽早发起关键请求
- 对可复用结果使用 [存储](/AIUI/guide/basic-storage) 或 [localStorage](/AIUI/api/storage-api) 做短期缓存
- 对首屏关键资源进行拆分，优先加载用户立即可见的数据

## 设计建议

- 把预拉取看成性能优化，而不是页面正确性的前提
- 为慢网络和缓存失效准备兜底加载状态
- 避免预拉取过多无关数据，降低启动阶段的网络与内存压力
