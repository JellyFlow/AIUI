# 性能数据

性能优化首先要建立在可观测的数据之上。AIUI 中常见的性能数据通常覆盖启动、渲染、脚本执行和网络请求四类问题。

## 重点关注哪些指标

- 启动耗时：从启动到首个可见界面的耗时
- 首次渲染：页面首次可交互前的布局与绘制时间
- JavaScript 执行：初始化脚本、数据处理和事件回调的耗时
- 网络延迟：接口响应时间、重试次数和弱网下的失败率
- 内存占用：页面切换后是否持续增长，以及长时间运行是否出现抖动

## 如何使用这些数据

- 先区分问题发生在 [启动性能](/AIUI/guide/performance-startup) 还是 [运行时性能](/AIUI/guide/performance-runtime)
- 对关键链路建立基线，避免只凭主观体感判断快慢
- 把页面级指标和接口级指标一起看，避免误判瓶颈位置
