# 弱网体验

弱网体验并不只是“请求慢”，还包括加载反馈是否清晰、失败后能否恢复，以及页面在高延迟场景下是否仍然可用。

## 设计重点

- 尽早展示加载状态，避免让用户误以为页面失去响应
- 为关键请求设置超时、重试和失败提示
- 优先保证核心信息可见，把次要内容延后加载
- 对可缓存的数据做本地复用，减少重复请求

## 常见优化方向

- 结合 [使用说明](/AIUI/guide/basic-network-usage) 设计统一的请求层
- 使用 [HTTPS](/AIUI/api/network-https) 时显式处理超时、错误码和降级文案
- 对实时流式场景评估 [Event Source](/AIUI/api/network-event-source) 或 [WebSocket](/AIUI/api/network-websocket) 的恢复策略

## 验证建议

- 在真实弱网环境下验证首次加载、重连和返回前台场景
- 分别检查卡片态与沉浸态页面是否都具备明确反馈
