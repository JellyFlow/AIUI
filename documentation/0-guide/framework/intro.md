# 介绍

AIUI 智能体框架的核心，不只是“把页面渲染出来”，而是把它作为一套意图驱动开发框架来组织。开发者需要定义智能体要承接什么样的用户意图、这些意图如何被处理，以及最终通过什么交互形态把反馈返回给用户；运行时再把这些部分串成一条完整链路。

下面这个交互式说明会从两个角度帮助你理解 AIUI 框架：

- 意图到反馈的完整链路由哪些部分组成
- 一个页面更新在运行时是怎么发生的

## 核心概念

AIUI 采用经典的逻辑层与视图层分离设计，但在一套意图驱动的智能体框架里，这个分层并不是孤立存在的，而是和智能体描述、智能体入口、页面结构一起协同工作：

1. **智能体描述 (Agent Description)**：由 `AGENTS.md` 定义智能体的身份、描述、能力和系统指令，决定平台如何理解这个智能体应当承接哪些意图。
2. **智能体入口 (Application Entry)**：由 `app.json` 定义页面入口和全局窗口配置，决定交互从哪里开始。
3. **逻辑层 (Logic Layer)**：运行在 QuickJS 中，负责解释用户操作、处理业务逻辑、调用 API 和管理数据状态。
4. **视图层 (View Layer)**：由 WXML 和 WXSS 组成，运行在 Ink 渲染引擎中，负责呈现意图、收集输入并渲染反馈。

这种架构不仅能提供流畅的界面更新能力，也让开发者能够把“智能体要承接什么意图”“交互从哪里开始”“逻辑怎么流转”“界面如何反馈”拆开组织，更适合 AI + AR 这种高频交互和持续状态更新的场景。
